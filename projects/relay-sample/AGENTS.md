# Relay Sample project guidance

Read `brief.md` and `decisions.md` before substantial work. Load `research.md`, `prototype-notes.md`, and only the shared Taste, Inspiration, and Resources sources that can change the result.

- This folder owns Relay Sample product context.
- Record approved product choices in `decisions.md`.
- Distinguish direct evidence from inference in `research.md`.
- Keep prototype observations in `prototype-notes.md`.
- Record implementation repositories and shippable artifacts in `deliverables.md`.
- Do not promote project-specific patterns into shared context without review.
- Do not publish or mutate external systems without explicit authorization.

## Sample boundary

- Relay is fictional and exists only as a worked example.
- Treat every person, organization, metric, quote, event, and technical dependency as synthetic.
- Preserve the structure and traceability lessons, not Relay's particular feature or domain.
- When a user starts real work, create a separate project rather than overwriting the sample unless they explicitly ask to adapt it.
