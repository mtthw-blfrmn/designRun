# Changelog

All notable changes to designRun will be documented here.

- Restored the source-backed control-center role with automatic refresh and context-aware agent handoffs.
- Added first-prompt onboarding, explicit project and deliverable lifecycles, and two missing prototype and image-direction workflows.

- Added project scaffolds, shared design sources, pattern promotion, and reusable agent workflows.
- Added a source-backed local control center modeled on Taste, To‑Do, Inspiration, Assets, Design System, Tools, Skills, and Projects.
- Added harness adapters, deterministic discovery and validation, and a monochrome local workspace app.
