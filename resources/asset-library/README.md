# Asset library

This folder owns reviewed, reusable visual material: backgrounds, mockup frames, textures, UI fragments, presentation structures, and other assets that are licensed and useful across projects.

Before promoting an asset from `resources/raw-assets/`, record its source, license, category, tags, best use cases, visual qualities, light/dark suitability, what to avoid, and review status. Agents should inspect the actual asset before using it.

The control center indexes only files explicitly listed in an `asset-library/**/manifest.json` `assets` array. Supporting files such as contact sheets may travel beside a collection under `supporting_files`, but they are not presented as reusable assets. Inspiration evidence in `resources/inspiration-assets/` is owned by the Inspiration library and never appears here.

The included spectral-gradient backgrounds are a worked example imported from the original local source workspace and approved by the repository owner for the public template. See `backgrounds/README.md` and its manifest.
