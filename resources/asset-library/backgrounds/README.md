Contact sheets for the original reviewed dark and light collections are in `contact-sheets/`. The four full-resolution files above are examples; the full 28-image source collection remains in the original local archive.

## Use guidance

- Put real product content above the background; atmosphere must not replace interface structure.
- Confirm text and control contrast in the final composition.
- Prefer the quiet variants for product surfaces. Reserve vivid gradients for launch or presentation moments.
- The repository owner approved this recovered example set for the public designRun template. Keep the manifest with the assets so that approval and source context travel with them.
