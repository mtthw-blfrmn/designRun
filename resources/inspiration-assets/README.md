# Inspiration assets

This directory holds the inspectable media connected to records in `inspiration/library/`. The current files were recovered from the original local source-workspace reference library so the template retains real visual evidence instead of text-only placeholders.

These are editorial references for critique and analysis, not reusable product assets. Product names, trademarks, interfaces, and underlying artwork remain the property of their respective owners. Eleven third-party-library screenshots were cropped by exactly 120px at the bottom to remove the library footer while preserving every captured product pixel above it. Each reference record retains the canonical product URL and source owner.

The Airbnb message capture and Grok live-test recording from the original library are intentionally excluded because they contain personal or session-specific context. Never commit personal account details, customer work, employer-confidential material, browser chrome containing identifiers, private sessions, or generated imitations presented as the original product.

See `resources/reference-provenance.md` for the provenance and release gate.
