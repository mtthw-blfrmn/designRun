# Sana chat workspace states

## Observed behavior

A persistent left sidebar frames a calm central conversation and grounded composer. The empty state offers starter actions; an active conversation may reveal a right-side panel for sources, files, and workflows.

## What works

Primary work remains centered while orientation and contextual memory occupy stable peripheral regions. Supporting context is revealed without crowding the thread.

## Principle to inherit

Combine a focused work surface with persistent orientation and optional contextual memory. Empty states should create momentum; side panels should answer a current need.

## Do not copy literally

Do not reproduce Sana’s labels, upsell card, navigation, or generic three-column productivity layout without validating the actual object model.
