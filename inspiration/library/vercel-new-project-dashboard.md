# Vercel new-project dashboard

## Observed behavior

Repository import and template discovery coexist in a broad, quiet layout. Template cards stay neutral while a believable interface plane enters from below at a shallow angle and is decisively cropped by the card.

## What works

Thin structure and broad alignment make several setup paths understandable without a dense admin shell. The angled preview creates dimensionality through real product detail rather than decoration.

## Principle to inherit

When a compact card needs product presence, use one legible interface plane, a restrained angle, and a purposeful crop; keep surrounding chrome visually quiet.

## Do not copy literally

Do not reproduce Vercel’s information architecture, brand, template names, repository content, or tilt every preview by default.

## Verification notes

The source is an evolving product entry point. Compare the current [new-project experience](https://vercel.com/new) before implementing a close behavioral analogue.
